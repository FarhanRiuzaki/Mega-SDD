# Constitution → `.claude/rules/` path-scoped emission (A6, v6.17.0)

**Status:** SHIPPED v6.17.0 (2026-08-17, 4019de0, CI green, both-tree suite 277/277). Round: 1 BLOCKER + 4 MAJOR + 3 minor folded (§Round amendments).
**Source:** adoption scan A6, USER-GREENLIT 2026-08-17. Platform capability: `.claude/rules/*.md` with `paths:` frontmatter globs load ON-DEMAND when Claude touches matching files (Claude Code v2.1.211+). Release 2 of the greenlit batches (A5 was rejected on measurement).

## Why

Constitution clauses today reach Claude only inside chain runs (bind Step 2.10 cross-referencing, unit Hard-rule injection 12.4). Outside the pipeline — a user editing governed files in a plain session — the constitution is invisible. Path-scoped rules make the clauses ride the code paths they govern, in EVERY session, at zero context cost when irrelevant.

## The grounding problem (and the only honest mapping)

Constitution clauses (`- <ID>: <text>` under `## §<letter>` headings) carry NO path information. Inventing globs per clause = fabrication (invariant #5). The grounded mapping: **Step 12.4 already injects clauses into unit Hard rules, and units carry `target_files`** — so a clause's paths = the union of `target_files` paths of every unit whose `## Hard rules` cites that clause ID. Literal paths only, zero generalization. A clause cited by NO unit is SKIPPED and listed honestly (never a fabricated glob, never a global always-load rule).

## Design

**NEW `scripts/emit-claude-rules.sh --vault=<dir> --cwd=<root> [--write]`** (deterministic, dry-run by default):
1. Parse `<vault>/constitution.md` clause IDs + verbatim text; parse each `<vault>/units/U-*.md` frontmatter `target_files` + body `## Hard rules` clause citations (`§?<ID>` token match).
2. Per cited clause → `.claude/rules/mega-sdd-<vault-slug>-<clause-id>.md`:
   - frontmatter `paths:` = sorted unique union of citing units' target_files (literal);
   - body = the clause line VERBATIM + provenance stamp: source path, constitution version + sha256, "GENERATED by mega-sdd — do not hand-edit; refresh via /mega-sdd:sync".
3. Refresh semantics: rewrite the full `mega-sdd-<vault-slug>-*.md` set; delete stale files matching the vault's **exact generated pattern** `mega-sdd-<slug>-<ID>.md` only (round M-3 narrowed this from prefix-match: a sibling-slug vault's rules and any hand-written file in the prefix are structurally undeletable).
4. Dry-run prints the plan JSON (clauses emitted / skipped-uncited / stale-removed); `--write` applies atomically.

**Wiring — OFFERED, never silent** (writing to `.claude/` is user config territory; no-silent-mutation doctrine):
- `generate-units` end: one proposal line (with keterangan) offering the emission when `constitution.md` exists; under `--auto` it is QUEUED as a notice, never auto-run.
- `sync.md` SYNC-REPORT: when emitted rules exist and `constitution_hash` (binding frontmatter) changed OR units were reconciled → propose refresh (same offer contract).

## Non-goals
No hook enforcement change (rules are context, not gates — the moat is untouched); no glob inference; no rules for KB/vault docs; no auto-write ever.

## Tests
NEW `tests/claude-rules/test-emit-claude-rules.sh`: clause→paths union correct; uncited clause skipped + listed; verbatim clause text + stamp; dry-run writes nothing; refresh removes stale prefix files ONLY (foreign `.claude/rules/` file untouched — the prefix-scope arm); deterministic re-run byte-equal; wiring greps (generate-units offer + sync refresh line + never-auto-run wording).

## Round amendments (blind reviewer, live payloads — all folded)

- **B-1:** the target_files harvest scanned the WHOLE unit file — a fenced YAML example or prose `- path:` bullet grounded rules with paths never in target_files (live-proven with `/etc/shadow`). Folded: frontmatter-block-only harvest.
- **M-1:** clause parse had no §-section scoping (the "heading context kept" comment was false) — a Revision-history line minted/overwrote clauses. Folded: §-heading state machine, fences skipped, first occurrence wins.
- **M-2:** citation regex lacked a LEFT boundary — `SUB-001` cited `B-001`. Folded: `(?<![\w-])` guard.
- **M-3:** prefix-match deletion let vault `pay` delete `pay-v2`'s rules (ping-pong on every refresh) and a hand-written prefix file. Folded: slug-exact generated-pattern match (also resolves the reviewer's m-1 spec-contradiction).
- **M-4:** `\S+` path capture + naive double-quoted YAML truncated spaced paths and emitted invalid frontmatter on quoted/backslash paths. Folded: rest-of-line capture with quote-stripping + single-quoted YAML scalars (`''` doubling).
- Minors: vacuous never-auto test arm de-vacuoused (title word "OFFERED" satisfied it); plan key renamed `skipped_ungrounded` (covers cited-by-pathless-units honestly); stale-arm fixture moved onto the generated pattern.
- 6 new payload-class test arms (f1–f5b) pin every fold.
