## 1. Arsitektur v8

```mermaid
flowchart LR
  PRD["PRD / brief / Figma"] --> G["GROUND<br/>script: manifest · pack · symbol-index"]
  G --> P["PLAN (1 fase model)<br/>PRD → context.md + units/U-*.md<br/>OQ P1 business = 1 batched ask"]

  P -. derive .-> VJ[(vault.json)]
  C -. on demand .-> D["DOCS lane<br/>emit prd/fsd/sit/uat/html"]
  C -. code moved .-> L["LIVE lane<br/>sync · drift · delta · multi-PRD"]
```

Tiga lane. **BUILD** (default) = GROUND (script) → `plan` → `bolts`. **DOCS** (opt-in) = emisi diturunkan dari units + kode + PRD + context.md. **LIVE** = keyed ke units + `bolts/U-*/binding.json` + `vault.json` turunan. Surface tetap 3 verb + one-timers; `/mega-sdd <prd>` mengusulkan chain 2-hop dengan **satu** konfirmasi.
