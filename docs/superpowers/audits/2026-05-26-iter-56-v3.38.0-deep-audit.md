### D1 — Iter 45 `--rollback` rail REVERSED (default safe → default DANGEROUS)

**Severity:** P1 HIGH (anti-halu rail violation; real safety break)
**Source dim:** D
**Evidence:** `execute-bolts/SKILL.md` L36 + L383 claim "default safe for non-idempotent"; actual menu at L391-402:
```
[Y] proceed (records applied_at per action)        # BATCH-APPLY ALL actions including idempotent: false
[N] cancel; review partial-state.json manually
[I] interactive (prompt before each action)        # The TRUE per-action confirmation
```

Default `[Y] proceed` triggers batch apply of ALL compensating actions including `composer_dep_added` (idempotent: false; runs `composer remove`), `migration_executed` (idempotent: false; runs `php artisan migrate:rollback`), etc. The documented "default safe" rail is the opposite of actual menu behavior.

**Impact:** User runs `--rollback`, picks `[Y]` (the default key), and accidentally triggers non-idempotent compensating actions on dep manifests / migrations. Real-world data loss risk.

**Fix:** Either (a) flip menu so `[I]` interactive is default (recommended — matches documentation), OR (b) update doc to remove "default safe" claim (acknowledges current dangerous behavior). Option (a) is the user's safety intent per Iter 45 spec.
