# grand-design-spec v0.6.0 — Design System Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the grand-design-spec skill to emit design-system content (UI components, tokens, a11y, brand voice) when source documents explicitly cover them — strict source-mirror invariant, no shape-based inference, no auto-prompts, no industry-standard defaults.

**Architecture:** Plugin marketplace with a single skill `grand-design-spec`. The skill is markdown-driven instructions to Claude. v0.6 changes are documentation edits across one SKILL.md file, three template files, two manifest files, and two release docs. No code, no compiled artifacts.

**Tech Stack:** Markdown (skill + templates), JSON (manifests), git for version control. Verification is read-after-edit + grep checks + manual smoke tests against synthetic PRDs.

**Spec source:** `docs/superpowers/specs/2026-05-08-grand-design-spec-v0.6-design.md`
