# Unit U-003 — Build the public Beranda page

## Goal

Render the Beranda page: organisation title, one-sentence tagline, the three services (title + paragraph) and a button to the Kontak page, responsive at 375px and desktop.

## Context (read first)

This is the PRD's landing page (PRD §Halaman Beranda; context.md#Overview) and reads every string from the U-002 config, never hard-coded. It sits in the existing `(blank-layout-pages)` route group so it reuses that layout and its Providers without a login (constitution C-004, C-003).

## Anchors

- src/app/(blank-layout-pages)/login/page.tsx:1-22 — thin `page.tsx` that exports `metadata` and renders a `@views/*` component; follow this shape
- src/app/(blank-layout-pages)/layout.tsx:12-24 — group layout (Providers + BlankLayout) reused as-is
- src/configs/companyProfile/index.ts — content source created by U-002

## Claims

- C-U003-01 "no beranda route exists yet" — expect: src/app/(blank-layout-pages)/beranda — must-not-exist
- C-U003-02 "the blank-layout route group layout exists" — expect: src/app/(blank-layout-pages)/layout.tsx — must-exist

## Hard rules

- DO NOT modify src/app/(blank-layout-pages)/layout.tsx
  Source: constitution.md C-004 — the existing group layout already serves public pages; changing it would also change /login and /register
- DO NOT add new package.json dependencies
  Ref: CLAUDE.md §Stack & Commands — the existing stack (MUI, next/link, react-hook-form, zod, TanStack Query, MSW) covers this unit; allowed_new_deps is empty
- NEVER hard-code organisation, tagline or service text in the view — ALWAYS read it from the companyProfile config
  Source: PRD §Halaman Beranda — konten statis dari file konfigurasi

## Implementation steps

1. Create `src/views/company-profile/HomeView/index.tsx` that renders `companyProfile.name` as the page `h1`, the tagline, the three services as MUI cards in a `Grid` that stacks at `xs: 12` (375px) and goes three-across from `md`, and an MUI `Button` labelled `Kontak` linking to `/kontak` via `next/link`.
2. Create `src/app/(blank-layout-pages)/beranda/page.tsx` following the login page shape: export `metadata` with title `Beranda` and render `HomeView`.
3. Write `index.test.tsx` with `renderWithProviders` asserting the `h1` shows the config name, the tagline and all three service titles and descriptions render, and the `Kontak` link has `href="/kontak"`.
