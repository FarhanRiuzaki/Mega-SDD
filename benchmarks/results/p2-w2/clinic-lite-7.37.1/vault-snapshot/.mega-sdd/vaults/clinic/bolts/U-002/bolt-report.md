## What was implemented

- `BOOKING_HOURS` = `{ start: '09:00', end: '17:00', lunchStart: '12:00', lunchEnd: '13:00', slotMinutes: 15 }`.
- `generateDaySlots(window?)` goes from 09:00 in 15-minute steps, skips starts in the half-open lunch interval [12:00, 13:00), and stops before 17:00. A window is clamped to max(start, 09:00) / min(end, 17:00), then starts are filtered with `from <= t < until`. The window is start-based, so it can only remove slots. A malformed window returns `[]`.
- `isBookableDate(date, today)` returns false if the date doesn't match `YYYY-MM-DD`, isn't a real calendar date (for example 2026-02-30), is before `today` (plain string compare), or falls on a Saturday or Sunday. The weekday comes from `new Date(y, m-1, d)`, a local calendar date with no timezone conversion.
- `availableSlots({ date, today, bookedStartTimes, window, now })` returns `[]` for a date that isn't bookable, otherwise `generateDaySlots(window)` minus the booked start times. On the current day it also drops slots where `slot <= now`. `now` is optional and there is no fallback to the system clock. A malformed `now` on the current day returns `[]` (fail closed).
- The module has no imports at all: no React, no network, no date library.
