# PRD: Webinar Platform

## 1. Overview
Hosts run live webinars for up to 1,000 attendees.

## 2. Registration
Attendees register with name and e-mail and receive a calendar invite.

## 3. Q&A
Attendees submit questions during the session; other attendees upvote them, and the host answers live or dismisses them.

## 4. Polls
The host launches single-choice polls; results are shown live as a bar chart.

## 5. Target Audience
When creating a webinar the host restricts registration to e-mail domains or to an uploaded invite list.

## 6. Dependencies
A session can depend on another session; attendees cannot register for it until they attended the prerequisite.
