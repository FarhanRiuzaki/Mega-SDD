# PRD: Asisten Pengetahuan Internal

## 1. Background
Karyawan menghabiskan rata-rata 40 menit per hari mencari SOP di Confluence.

## 2. Tanya Jawab
Karyawan mengetik pertanyaan; asisten menjawab dari SOP yang terindeks.

## 3. Context
Asisten menyimpan 20 giliran percakapan terakhir per sesi dan menghapusnya saat sesi ditutup.

## 4. Sources
Setiap jawaban menampilkan daftar dokumen sumber beserta tautan dan tanggal revisi terakhirnya.
