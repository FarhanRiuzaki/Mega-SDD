# PRD: News Reader
## Functional Requirements
### FR1 Sources
Users MUST be able to add RSS and Atom feed sources; invalid feeds MUST be rejected.
### FR2 Scope (OAuth)
The client MUST request only read scopes.
### UC3 Version History
Editors MUST see every revision of an article.
### F4 Riwayat
Riwayat baca MUST tersimpan 30 hari.
### F-5 Sources
Hyphenated id control.
