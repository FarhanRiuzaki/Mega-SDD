# PRD: DocEditor
## 4. Features
### 4.1 Real-time collaboration
Two users MUST see each other's edits within 500 ms.
### 4.2 Version History
Users MUST be able to restore any prior version; restores MUST be audited.
### 4.3 References
Users MUST be able to insert citations; the bibliography MUST auto-update.
### 4.4 Context
The side panel MUST show the context (linked tickets) of the current paragraph.
