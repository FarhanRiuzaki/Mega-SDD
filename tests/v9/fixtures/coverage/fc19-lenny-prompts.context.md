# fc19 — the natural coverage exclusions (test sidecar: the vault's context.md)

## Coverage exclusions

- "Description: What is it?" — document context — background for the flows, no behaviour of its own
- "Problem: What problem is this solving?" — document context — background for the flows, no behaviour of its own
- "Why: How do we know this is a real problem and worth solving?" — document context — background for the flows, no behaviour of its own
- "Success: How do we know if we've solved this problem?" — success measurement — tracked outside the software
- "Audience: Who are we building for?" — who the product is for — context for the flows
- "When: When does it ship and what are the milestones?" — project schedule, not software behaviour
