# PRD — Pembukaan Rekening Online

## 1. Ringkasan
Nasabah dapat membuka rekening tabungan dari aplikasi.

## 2. Latar Belakang Bisnis
Pembukaan rekening saat ini hanya di cabang.

## 3. Pernyataan Masalah
Antrian di cabang panjang.

## 4. Tujuan Pengembangan
Menambah nasabah baru 20%.

## 5. Metrik Keberhasilan
- 5.000 rekening baru per bulan.

## 6. Persona Pengguna
- Mahasiswa, pekerja muda.

## 7. Pemangku Kepentingan
- Divisi Retail, Divisi IT, Kepatuhan.

## 8. Kebutuhan Fungsional
### 8.1 Verifikasi e-KTP
Sistem memverifikasi NIK ke Dukcapil.
### 8.2 Setoran awal
Nasabah melakukan setoran awal via VA.

## 9. Asumsi
- Nasabah memiliki e-KTP.

## 10. Ketergantungan
- API Dukcapil.

## 11. Risiko
- Downtime Dukcapil.

## 12. Di Luar Lingkup
- Rekening giro.

## 13. Pertanyaan Terbuka (OQ)
- Apakah limit setoran awal Rp100.000?

## 14. Daftar Istilah
- VA: virtual account.

## 15. Riwayat Perubahan Dokumen
- 0.1 draft.

## 16. Persetujuan Dokumen
- Kepala Divisi Retail.
