# PRD: Mobile Banking v2
## 3. Fitur Transfer
### 3.1 Sumber
Nasabah MUST memilih rekening sumber dari daftar rekening aktif miliknya.
### 3.2 Tujuan
Rekening tujuan MUST divalidasi via inquiry nama sebelum konfirmasi.
### 3.3 Riwayat
Nasabah MUST dapat melihat riwayat transaksi 90 hari terakhir dan mengunduh e-statement.
### 3.4 Konfirmasi
Transfer MUST memakai OTP.
