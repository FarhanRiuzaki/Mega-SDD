# PRD: Social Wallet
## Overview
A wallet with a social feed.
## Transfers
Users send money to friends.
## Timeline
Users see their friends' payments, newest first.
## Jadwal
Nasabah melihat jadwal autodebet bulan ini.
## Lampiran
Nasabah melampirkan foto struk ke transaksi.
## Approvals
A second admin approves payouts above Rp10.000.000.
## Summary
Before paying, users see the amount, fee and total.
## Exclusions
Promo cashback excludes QRIS transactions.
## Tidak Termasuk
Cashback tidak berlaku untuk tarik tunai.
