# PRD: Docs editor
## 1. Overview
A collaborative editor.
## 2. Scope
### 2.1 Real-time Collaboration
Multiple users edit one document at once.
### Version History
Users can restore any previous version of a document.
### References
Users can insert citations from Zotero into the text.
### Context
The sidebar shows the comment thread for the selected paragraph.
## 3. Ruang Lingkup
### Sumber
Nasabah memilih rekening sumber dari daftar rekening aktif.
### Riwayat Perubahan
Setiap perubahan limit tercatat dan bisa dilihat nasabah.
