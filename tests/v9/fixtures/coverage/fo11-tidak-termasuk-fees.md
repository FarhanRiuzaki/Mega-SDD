# PRD: Paket Tabungan Plus
## 1. Tujuan
Meningkatkan CASA.
## 2. Termasuk dalam Paket
Transfer antarbank gratis 25x/bulan.
## 3. Tidak Termasuk
### 3.1 Transfer Luar Negeri
Biaya Rp50.000 per transaksi WAJIB didebet dari rekening sumber.
### 3.2 Tarik Tunai ATM Bank Lain
Biaya Rp7.500 WAJIB dikenakan mulai penarikan ke-6.
## 4. Kartu Debit
Kartu WAJIB mendukung GPN.
