# God-review stage 4 — `bind-codebase` (the moat's heart)

**Date:** 2026-07-02 · **Method:** adversarial multi-agent review — 8 blind lenses (verdict-semantics, conflict-gate, validators-empirical, ground-truth-parity, state-map-handoff, prose-vs-enforcement, schema-drift, consumers-crosscut) → dedup → refute-by-default verification (1 skeptic per finding; High requires an empirical repro). 36 agents, ~2.6M tokens. Raw 43 → dedup 27 → **20 CONFIRMED + 2 DOWNGRADED, 5 REFUTED**.

**Severity after verification:** 8 High / 9 Medium / 5 Low.

**Shipped as v4.57.0** in four batches (4A moat-gate integrity, 4B handoff-validator correctness, 4C producer parity, 4D contract truth), pinned by `tests/god-review-s4/`. Spec amendment: `docs/superpowers/specs/2026-06-10-living-vault-continuous-sync-design.md` §4.

## Dominant defect classes

1. **Enforcement wired to the wrong write path (again — the stage-3 headline class, one stage downstream).** The moat-state writer (`validate-handoff-binding-units.sh`) fired on UNIT writes only, while CONFLICT truth is written on the BINDING path — so the exact lane the docs attest is gate-equivalent ("sync never bypasses the moat") deterministically bypassed invariant #2 (BC-GATE-1, reproduced end-to-end with the real hooks). Corollaries: the anti-self-bypass guard covered Bash but not the sibling Write/Edit tools (BC-BYPASS-1); a comment token disabled it (BC-BYPASS-2); deleting binding.md flipped FAIL→PASS one indirection later (BC-BINDING-DELETE).
2. **The validator judges a grammar the producer doesn't write (and vice versa).** Substring "resolved" resolved active conflicts (BC-GATE-2); the numeric fresh-OQ form bind's own template mandates was invisible (BC-HANDOFF-1); auto-resolved tech-OQs the validator demanded citations for false-blocked every clean brownfield run (BC-HANDOFF-2); the official recovery channel (resolve-oq --binding) wrote markers no validator reads (BC-RESOLVE-TOKEN); C-NNN blocking headings passed the blocking validator while the advisory one counted them (BC-VAL-6).
3. **A protection defeated at its first consumer.** The v4.56.0 truncation exception (absence in a capped map section ≠ evidence) was mapped to `task_type: create` by generate-units' unconditional UNKNOWN row — the exact duplicate-implementation the exception shipped to prevent (BC-TRUNC-1). Same shape: snapshot sha256 "verified" a map whose code had moved (BC-STALE-1); preflight FATAL-blocked the legacy map path bind itself probes (BC-PREFLIGHT-LEGACY).
4. **Positive attestation without delivery.** "Read-only" advisor with Bash in its tool list (BC-ADVISOR-RO-1); "anchor accuracy is enforced at bind time" with no mechanism (BC-ANCHOR-ATTEST-1); a Recommendations feature dead on arrival because its confidence gate excluded the only confidence its producer emits (BC-RECOMMEND-CONF-1).
