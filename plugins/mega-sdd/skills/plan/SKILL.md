# Plan — PRD or KB → context.md + units in ONE phase

**Announce at start:** "I'm using the plan skill to turn the source into context.md + units. `mega-sdd-trace:plan`"

> **Skill instruction language:** this skill reasons in English. **Generated docs match the PRD language**; chat defaults to **Indonesian + English technical terms**; precedence = explicit request > the language the user writes in > Indonesian for short/ambiguous input. Tier-1 tokens stay English (→ `plugins/mega-sdd/references/output-language.md`). *(Greenfield-reachable: "spec out this feature" / "pecah PRD ini" runs with no `.mega-sdd/` signal, so it carries the policy itself.)*

## What this phase is (and is not)

`plan` is the one pre-code phase (spec `docs/superpowers/specs/2026-09-10-v8-fused-pipeline-design.md` §3 / App. C3): read the source once, write `context.md` (layout-3, one file), write the units from source + context, derive `vault.json`, run the validators, and ask the human ONCE. Binding does not happen here — **JIT bind runs in `execute-bolts`** (at run start and again at each task; per dispatch under `--agents`; it reads each unit's `## Claims`), so a brownfield unit carries claims (a contract), never verdicts.

- **Input:** a PRD / BRD file (positional), or `--kb=<kb-dir>` — an `extract-intelligence` knowledge base (`README.md` + `modules/*.prd.md`, one module per self-slice; resolved §6 OQs land pre-resolved; `references/kb-input.md`). A free-text brief is not a plan input: the front door takes it to the direct/assisted lanes, or under `--guarded` writes it to a seed-PRD file first (`references/brief-input.md`) and passes that file.
- **Output:** `<vault>/context.md` + `constitution.md` + `_meta/ai-consumer-guide.md` + `vault.json` + `units/U-*.md` + `units/_index.md`. No handoff YAML in this lane — the front door re-derives state from disk (`derive-state.sh`) before the `execute-bolts` hop.

## Anti-hallucination rails (THE MOAT — never relax)

These rails are the reason this phase exists:

- **Ground everything in the PRD (+ Figma via MCP; under `--kb`, the KB).** Not explicit in the source → NOT in the body → an Open Question. No best-practice insertions, no "probably they meant", no defaulted standards (WCAG, palettes, SLO targets), no invented UI when Figma is referenced but unreachable.
- **Every claim cites its source.** Flows/DBML/NFR rows cite `PRD §<X.Y>`; every unit carries `prd_source:` (PRD heading slug or `:line`) AND `context_source: context.md#<anchor>`; a PRD anchor (a heading with text or no sub-heading; a text-less one's sub-headings stand in) with no unit, no OQ carrying `[covers: <ref>]` and no `## Coverage exclusions` line is a `plan_coverage_gap` halt, never silently dropped.
- **Brownfield claims are contracts, not verdicts.** `## Claims` lines say what the unit EXPECTS of existing code (symbol-index query at PLAN); the verdict is written by the JIT bind script into `bolts/U-XXX/binding.json` in `execute-bolts`. Never write CONFIRMED/CONFLICT in a unit.
- **`--auto` never bypasses the rails.** Autonomy skips logistics only; it never auto-answers a P1 business OQ, never invents field values, never skips the batched ask (an unanswered P1 business OQ stays `blocking` and the units that need it stay blocked at bolts).
- **Units obey the unit contract verbatim** (`references/unit-schema.md`): closed Hard-rule grammar, `target_files` whitelist, ≥1 `acceptance_test`, Anchors when evidence exists, xs body diet.

## Inputs & flags

- `<prd>` (positional; required unless `--kb`) — PRD/BRD file (`.md` / `.pdf` / `.docx`; PDF via the Read tool / `pdf` skill, DOCX via the `docx` skill). A non-`.md` PRD is first rendered verbatim to `.mega-sdd/sources/<name>.md`, the `<prd>` from Step 0 on (the gate reads markdown only; `references/plan-procedure.md §Step 0`). Figma URLs inside the PRD → `ToolSearch query:"figma"`; no MCP and no screenshots → OQ, never invented UI.
- `--kb=<kb-dir>` — the source is an `extract-intelligence` KB (legacy rebuild): Step 0 pins it, Steps 1–4 read it, Step 5 covers it — all per `references/kb-input.md`. A detected KB with no positional PRD → implicit `--kb` (kb-input §KB auto-detection). Accepted architecture decisions `<kb>/decisions/ADR-*.md` (`Status: accepted` only; `proposed` surfaces as an OQ, never a decision) are input documents — the architecture-advisor record, `plugins/mega-sdd/references/architecture-advisor.md`; procedure in `references/kb-input.md` item 7.
- `--phase=N` — `--kb` on a legacy numbered-tree KB only: scope to Phase N of `99-rebuild-architecture/suggested-phasing.md` (default `1`; `phase`/`phase_total` persisted via the Step-3 `derive-vault-json.sh --patch`). Against a PRD-kontrak KB it is logged and ignored (module = phasing unit) — `references/kb-input.md`.
- `--vault=<dir>` — output dir; default `.mega-sdd/vaults/<slug>` (slug from `derive-plan-pins.sh`). Existing `context.md` there → refuse unless `--regenerate` (never silently overwrite; `--reconcile` below never rewrites `context.md`).
- `--mode=new|existing` — `implementation_mode` pin; the front door passes it from its starterkit/brownfield detection; default `new`.
- `--scope=<id>` — one scope of a multi-scope PRD (`scopes:` block); picker + filter + the `scope_not_declared_in_prd` halt per `references/scope-flow.md`. A PRD without a `scopes:` block is single-scope (one report line, no ask).
- Unit flags — `--max-complexity=small|medium|large` · `--strict-deps` (default) / `--loose-deps` / `--no-deps` · `--collision-policy=<extend|verify|skip>` · `--adversarial-subagent` / `--no-adversarial-review` · `--regenerate` (keeps `_authored_by: human` units): `references/unit-procedure.md §Unit flags`. `--no-constitution` skips `constitution.md` (Step 3). `--auto` — logistics only (rails above).
- `--lite` — accepted, no effect (plan is the pipeline).
- `--reconcile` — the sync-lane hop on a layout-3 vault, after `scripts/rebind-units.sh`. NO new units (a new requirement goes `diff-vault` → `plan --regenerate`) and NO rewrite of `context.md`: flip each unit's `task_type` from its refreshed `bolts/U-XXX/binding.json`, recompute `status`, mark superseded units, regenerate `units/_index.md`, run `derive-vault-json.sh`, and list every flip in chat with its claim id — `references/task-typing.md §Reconcile pass`. Unresolved CONFLICTs are left for `resolve-oq --binding` and the unit stays gated; a unit whose binding is absent is reported as `not re-bound — run rebind-units.sh`, never guessed.

## Procedure (inline skeleton = authoritative; detail → `references/plan-procedure.md`)

**0. Pins + setup (script, 0 tokens).** **Run** `bash <plugin-root>/scripts/derive-plan-pins.sh --cwd=<root> --prd=<prd> [--vault=<dir>] [--mode=<mode>]` (under `--kb`: `--kb=<kb-dir>` in place of `--prd`) → `{prd_path, prd_sha256, author, slug, vault, project_scale, implementation_mode, vault_exists}`. `vault_exists` + no `--regenerate` → stop with one line. `project_scale` is the xs switch (`xs` ⇔ 1–3 screens ∧ ≤2 entities ∧ ≤3 flows — structure count, never judgment; a KB run is always `standard`). `prd_status` = `draft` only when the PRD says so (title/frontmatter/"DRAFT"); else `final`. Under `--kb`, also the KB Step-0 items (grammar detection, the two advisory preflights — `references/kb-input.md`). Nothing here is asked.

**1. Read the source in full** (PRD + Figma frames + attached docs; under `--kb` the README, `data-mutation-policy.md` and every `modules/*.prd.md` per `references/kb-input.md §Consumption`). Multi-scope PRD → `references/scope-flow.md` (Step 0.9). Under `prd_status: final` never pause for gaps — every gap becomes an OQ.

**2. Extract before writing** — the internal working table (product, shape, screens, entities, flows, decisions, constraints, gaps, design-system flags `HAS_*` from a SOURCE only). **Rail A1 anti-rot:** write the table's row counts as the contract at the top of your working notes; the Step 6 verdict table must reconcile against it. **Self-slice:** when the PRD exceeds ~40 KB or names ≥3 modules, plan per module (`--scope` / module loop; under `--kb` the module IS the slice) — one `context.md`, units written module by module, never one giant pass.

**3. Write `context.md`** from `references/templates/context.md` (read the template; four mandatory H2 anchors `## Flows` / `## Data model` / `## Constraints` / `## Open Questions`; `## Decisions` / `## Overview` only when sourced; frontmatter = lock scalars + Step-0 pins + `stakeholders` from the PRD or `["[Pending]"]`). Content rules per section = `references/context-authoring.md` (readability, operator-UX capture, OQ classification, xs); OQ conventions `plugins/mega-sdd/references/vault-core.md §OQ-conventions` + §Auto-classifier heuristics. Flows = Mermaid + DoD per flow (Mermaid-flows hard rule). Then `constitution.md` (§A–§F, every clause source-cited — `vault-core.md §constitution`) unless `--no-constitution`, and `mkdir -p <vault>/_meta && cp "<plugin-root>/skills/plan/references/templates/ai-consumer-guide.md" <vault>/_meta/ai-consumer-guide.md`.
   - **OQ classification** on every OQ (business → `blocking`; tech → `scan | recommend`; conservative default business/blocking/low; business wins ties). **An OQ reaches a human only when the AI cannot answer it:** every tech OQ is DECIDED here — probe now (manifest / symbol index / file), pick reuse-first, write `[x]` + `→ **Resolved v<X.Y>** (AI decision, <date>): <pick>` + the `## AI Technical Decisions` row (`plugins/mega-sdd/references/vault-core.md §AI technical decisions`). Never `[tech / blocking]`; a missing fact or a PRD-vs-repo contradiction is `[business]`. **xs:** P2 business OQs are born `**Deferred (plan)**:` (never asked; resurfaced in the report).
   - **Run** `bash <plugin-root>/scripts/derive-vault-json.sh --vault=<vault> --patch=<patch.json>` ONCE (patch = `source_documents`, `design_system_flags` [+ `design_system`] [+ scope block] + per-OQ classifier records; the pins come from the frontmatter — never hand-write `vault.json`; exit 4 → halt `memory_in_use`).

**4. Write the units** — the unit walk is `references/unit-procedure.md` (Steps 2 → 12.7) with **sources = PRD + context.md**; the plan rules on top are in `references/plan-procedure.md §Step 4`: flow-step → artifact derivation (`references/decomposition-rails.md`); **task_type**: greenfield (`implementation_mode: new`) ⇒ every unit `create`; brownfield ⇒ query the symbol index per candidate (`bash <plugin-root>/scripts/query-symbol-index.sh --cwd=<root> --name=<symbol>`; hit ⇒ `verify`/`extend` + `## Anchors` + `## Claims` lines, `references/task-typing.md`; miss ⇒ `create` + a `must-not-exist` claim) — never a CONFIRMED/CONFLICT verdict; group + atomize; strict `depends_on` (cycles → halt `cycle_detected`); modules/squads; IDs; `target_files`; `acceptance_test` + render test + UI contract + adversarial pass (`references/adversarial-test-prompt.md`); **write each unit** from `references/templates/unit.md` with `prd_source:` + `context_source: context.md#<anchor>` (never `vault_source`), the zero-reader fields dropped, the **xs body diet** for the router's xs class; `units/_index.md` (`references/unit-procedure.md §Step 11`). Under `--kb`: KB-derived Hard rules + Anti-patterns per `references/kb-input.md`. **Last: `## Coverage exclusions`** (the last H2 of `context.md`): one line per censused anchor no unit's `prd_source` names and no OQ decides with `[covers: …]`, `- "<exact heading text>" — <reason>` (`--kb`: `- <m>.prd.md#"<heading>" — <reason>`); never a requirement (`references/context-authoring.md §Coverage exclusions`).

**5. Validate (scripts; halts are findings, never patched around).** **Run** in order: `validate-unit-spec.sh --cwd=<root>` (scans every unit under `.mega-sdd/vaults/*`; an optional `--vault=<name|dir>` only scopes the EXIT CODE to that vault — the state file stays project-wide) (halts `unit_underspecified` / `hard_rule_unparseable` / `prd_source_unresolvable`; `xs_body_advisory` = trim); `validate-flow-coverage.sh --cwd=<root>` (BLOCKING gate); `validate-sibling-consistency.sh --cwd=<root>` (project-wide — it takes NO `--vault=`; that arg is `exit 2` + `STATUS: ERROR`); **`validate-plan-coverage.sh --cwd=<root> --prd=<prd> --vault=<vault>`** (under `--kb`: `--kb=<kb-dir>` in place of `--prd` — every module heading) → exit 1 = halt `plan_coverage_gap` naming each heading with no decision (add a unit, a `[business]` OQ carrying `[covers: <prd>#<slug>]` — nothing else in an OQ decides — or its `## Coverage exclusions` line, which `next_action` prints paste-ready; a placeholder or pending-decision reason is a gap too; the gap is the finding; one `--prd` per source the vault pins). Then `derive-vault-json.sh --vault=<vault> --event='{"event":"units_generated","count":N}'`, then **`validate-vault-oqs.sh --cwd=<root> --file-path=<vault>/context.md --strict-tech`** — `oq_tech_undecided` (a tech OQ left for a human: decide it) / `oq_decided_business_signal` (the AI decided a business matter: re-open, tag `[business]`).

**6. ONE batched ask — the only interaction point of this phase.** Collect the open **P1 `[business]`** OQs (plus L0 toolchain items the chain handed over; under `--kb` the targets of `references/kb-input.md §KB Q&A loop`). Present ONE `AskUserQuestion` with ≤4 questions, each: the OQ text + its PRD context (side-by-side quote), `[1]` recommended answer (grounded or "no recommendation — needs stakeholder"), `[2]` Defer, `[3]` Out of scope, + "Other" free text; **keterangan mandatory** (question source + per-option explanation, Indonesian for ID users). More than 4 P1 business OQs → ask the 4 with the largest unit blast radius; the rest stay `blocking` (listed in the report; their units stay blocked at bolts). Apply answers to `context.md ## Open Questions` (`→ **Resolved**` / `**Deferred**` / `→ Out of Scope`), re-run `derive-vault-json.sh`, refresh `binding_refs` on the units that cite them, then re-run `validate-plan-coverage.sh` (a resolved OQ covers nothing: its heading now needs a unit or a declaration). Headless (`AskUserQuestion` unavailable) → the business OQs stay open; never self-answer a business OQ inside the skill (tech OQs were already decided at Step 3).

**7. Self-check + present.** Verdict table vs the Step-2 contract (screens / entities / flows / OQs / units — counts must reconcile; a mismatch is fixed, never explained away); anti-halu + readability checklist (`references/context-authoring.md §Step 7`). Chat summary: vault path, counts, project_scale, top blocker OQs, the coverage exclusions (count + every `heading — reason` line) and the headings only an open OQ decides (`oq_only[]`, every `heading ← OQ-ID` line), `NEXT: /mega-sdd --resume` (the front door dispatches `execute-bolts --all --lite`). **HTML render (opt-in):** only with `render_html: on` in `.mega-sdd/config.yaml` — `bash "<plugin-root>/scripts/render-html.sh" <vault> --index` fail-open; default: none (regenerable via `/mega-sdd:emit html`). No "I have created…" preamble.

## Halt conditions (index — YAML per type in `plugins/mega-sdd/references/halt-protocol.md`)

`plan_coverage_gap` (Step 5, ALWAYS STOP) · `cycle_detected` · `unit_underspecified` · `hard_rule_unparseable` · `prd_source_unresolvable` · `acceptance_path_unowned` (Step 5; re-gated at execute-bolts) · `unit_oq_trace_missing` · `dedup_ambiguous` · `interface_ref_missing` · `cross_squad_dep_invalid` / `cross_squad_ambiguous` · `cross_module_dep_invalid` / `module_cycle_detected` · `starterkit_rule_citation_missing` (a legacy unit, Step 5) · `scope_not_declared_in_prd` · `oq_tech_missing_mode` / `oq_recommend_underspecified` / `oq_scan_missing_query` / `oq_recommend_citation_invalid` / `oq_tech_undecided` / `oq_decided_business_signal` · `memory_in_use`. Every halt emits the unified `blocker` envelope with keterangan; `emitted_by: plan`.

## Quality bar

Grounded (every non-trivial claim cites PRD §) · honest about gaps (OQs over guesses; the coverage rail is mechanical) · ONE ask, at the end · units executable as-is by `execute-bolts` (unit contract: `references/unit-schema.md`) · counts reconcile (A1) · language match.
